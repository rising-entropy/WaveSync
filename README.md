# WaveSync

Imagine a site where you can join in - create your own playlist and invite friends to jam together! Control the playlist and the room. Born out of a personal need, WaveSync is an attempt to re-create that feeling of listening to songs together, sharing a earphone.

Building this as a FOSS, so any and every contribution is really appreciated! Thanks for being here!

## Stack

We will be doing this in a primarily Node stack with Bun runtime using TypeScript.

- Server code in Effect
- Client code in React
- PostgreSQL for Database
- Min.io for File Storage

## Scope of Work

- Login / Sign-up flow for users
- Exploring the library of songs and contribute to the library
- Create custom playlists - make them public - explore public playlists
- Create custom rooms, join public rooms to listen to the songs
- Host controls to the room creator - play, pause, seek, change song. Manage the room access
